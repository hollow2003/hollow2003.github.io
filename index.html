II.

研究方向Research

毕设课题：基于 LLM 规划与 VLM 感知的分层行为树机器人操作框架。从一句自然语言指令出发，LLM 自动生成行为树，行为树按需调用 VLM 感知环境，执行状态实时反馈回规划层实现动态 re-planning，最终在真机上验证端到端闭环。 Thesis topic: a hierarchical behavior-tree framework for robot manipulation, combining LLM planning with VLM perception. Starting from a natural-language instruction, an LLM generates the behavior tree; the tree invokes VLM perception on demand; execution feedback flows back to the planner for dynamic re-planning — validated end-to-end on a real robot.
